# 🔬 实验室换能器设备实验预约系统

专为实验室**单台换能器设备**定制的轻量级预约排期系统。解决设备资源紧张、提前排期下一周实验、以及实验时间和人员灵活调换的需求。

---

## ✨ 核心特性

1. **👉 快速预约下一周**
   - 顶部专门提供 **「👉 快速预约下一周」** 醒目绿色按钮，一键快速进入下周排期视图，方便实验室成员在周末或周五提前锁定时段。
2. **严密的时间冲突排他检测**
   - 单设备排他设计，毫秒级检测时间段重叠。
   - 若与其他同学预约重叠，系统自动精确提示冲突人员与时段（如：“与 张三 09:00~12:00 冲突”），杜绝撞车。
3. **极度灵活调整（时间与人员可随时变动）**
   - **调整时间**：点击已有预约卡片，直接修改日期与起止时间，自动再次做防重叠校验。
   - **变更/转让人选**：实验人员私下协商转让设备时段，直接修改姓名即可完成交接。
   - **取消释放**：临时有事一键取消预约，时段即刻释放给其他同学。
   - **安全保护**：预约时可选择填写 4 位数字 PIN 码防止他人误碰（留空则免密自由调整）。管理员万能口令为 `admin888`。
4. **📱 手机与局域网多人协同**
   - 只要连接实验室**同一个 WiFi 或局域网**，手机或笔记本浏览器输入 IP 网址即可直接查看与填报，无须安装任何 App。
5. **📋 便民实验室办公功能**
   - **一键复制群排班**：点击「📋 复制群排班」，自动生成排版清晰的整周日程文本，可直接粘贴发到微信群/QQ群。
   - **一键导出 Excel**：点击「📊 导出 Excel」，一键下载 `.xlsx` 排班表，方便打印或存档。
6. **零环境门槛**
   - 数据保存在本地轻量 SQLite 数据库 `reservations.db`，数据独立自闭环，拷走即可备份。

## 🚀 启动与使用方式

### 方式 1：Windows 双击一键启动（最推荐）
直接双击目录下的 **`启动预约系统.bat`** 文件：
1. 黑框控制台会自动启动服务。
2. 约 2 秒后系统会自动为您在默认浏览器打开系统主界面：`http://localhost:8000`。

### 方式 2：命令行启动
在当前目录下打开 PowerShell 或 CMD，运行：
```bash
python app.py
```
然后在浏览器访问：`http://localhost:8000`。

## 📱 手机端使用指南（Mobile First 体验）

本系统采用 **手机端优先（Mobile-First）** 深度重塑，完美适配任何手机屏幕尺寸：

1. **微信直接扫码打开**：
   - 电脑启动系统后，直接点击右上角 **「📱 扫码访问」**（或查看命令行黑框中的 IP）。
   - 实验室同学只需掏出手机打开 **微信扫一扫** 或 **手机相机** 扫码，秒开网页，免去输入复杂网址的烦恼！
   - *（前提：手机与电脑连接同一实验室 WiFi 或热点）*

2. **手机专属触控交互**：
   - **横向滑动星期胶囊**：周一至周日 7 天随心左右滑触切换，清楚标明哪天已约、哪天空闲。
   - **智能空闲时段指引**：系统自动计算空闲时间缝隙，直接呈现浅绿色「✨ 13:30~17:30 空闲可约」卡片，手指点一下直接预选该时间，无需心算空档。
   - **手机原生级底部抽屉（Bottom Sheet）**：弹窗自手机底部顺滑升起，大输入框、大快捷时段胶囊，单手操作极为舒适。
   - **大拇指吸底操作栏**：【📋 复制排班发微信群】与【➕ 填写实验预约】常驻屏幕下方，随时可点。

3. **保存到手机桌面（如同独立 App）**：
   - **iPhone (Safari 浏览器)**：点击底部分享按钮 ➔ 选择 **「添加到主屏幕」**。
   - **Android (微信/系统浏览器)**：点击右上角菜单 ➔ 选择 **「添加到桌面」**。
   - 之后在手机屏幕上就会出现一个独立的「换能器预约」图标，下次一按即开！
